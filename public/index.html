Photos API test for John Bric's Photo Gallery Application

This HTML/JS page tests the Photos API (/routes/api/api-photos.js) by doing the following:

  • listing all photos
  • creating a photo
  • finding the created photo
  • modifying the description of the found photo
  • adding a comment to the found photo
  • deleting the found photo

    • See the console for output of the test results.
